# 🧠 Bilingual General Aptitude & Reasoning Testing System

A modern, high-performance web platform for competitive exam preparation (UPSC, WBCS, SSC CGL/CHSL, Banking IBPS/SBI, Railways RRB, Campus Placements).

## 🌟 Key Features

- **📚 10 Complete Question Sets (500 Questions Total)**:
  - Quantitative Aptitude (Arithmetic, Commercial Math, Mensuration, Geometry)
  - Logical Reasoning (Series, Coding-Decoding, Blood Relations, Seating, Syllogisms)
  - Verbal Ability & English Language Comprehension
  - Data Interpretation & Data Sufficiency
- **⏱️ Dual Timing System**:
  - **Practice Stopwatch Widget** with Play/Pause and Reset controls for tracking individual practice sessions.
  - **45-Minute Countdown Timer** for 50-Question Timed Mock Tests with real-time question palette and instant score evaluation.
- **🌐 Dual-Language Switching**:
  - Toggle between **English**, **বাংলা (Bengali)**, or **Both (Bilingual side-by-side)** with clean neutral typography (no flag icons).
  - **English Digits (0–9)** strictly used across all texts, formulas, question indexes, and timers.
- **💡 Rich Descriptive Solutions**:
  - Step-by-step mathematical derivations, formulas, calculation breakdowns, and shortcut tricks for every question.
- **🛠️ Built-in Utilities**:
  - **Interactive Scratchpad / Rough Canvas** with color pens & eraser.
  - **Formula & Shortcut Cheat Sheet** modal.
  - **Bookmark System** with LocalStorage persistence.
  - **Dark / Light Theme** toggle.
  - **Web Audio Sound Effects** for correct/incorrect answers.

## 🚀 Deployment

### Deploy to Vercel
1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Other** / Static HTML.
3. Root Directory: `./`
4. Click **Deploy**!
